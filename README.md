# CIS-483 EcoLogix

MNSU CampusEco is a campus logistics web application designed to help manage package deliveries at Minnesota State University, Mankato.

## Team Members

- Ibrahim Traore
- Austin Madugla
- Sifan Adugna
- Ruth Mechegia

## Phase 1

Phase 1 focuses on the static frontend interface using HTML and CSS.

The project includes:

- Central Hub Operator interface
- Eco-Transit Courier interface
- Campus End User interface
- User registration page
- Shared navigation and styling
- HTML5 form validation
